# Finance Calculator

## Overview

This project is a Python-based command-line application that performs common financial calculations. Users can calculate investment growth using either simple or compound interest, as well as estimate monthly repayments on a home loan (bond).

The project demonstrates user input validation, error handling, financial calculations, and command-line application development.

## Features

- Investment calculator
- Simple interest calculations
- Compound interest calculations
- Bond repayment calculations
- Input validation for all user entries
- Error handling using try/except blocks
- User-friendly command-line interface

## Technologies Used

- Python 3
- Math Module

## How It Works

The application provides two calculation options:

### Investment Calculator

Users enter:

- Initial deposit amount
- Interest rate
- Investment period in years
- Interest type (simple or compound)

The program calculates the future value of the investment.

### Bond Calculator

Users enter:

- Current value of the property
- Interest rate
- Repayment period in months

The program calculates an estimated monthly bond repayment.

## Example Usage

### Main Menu

```text
Investment - to calculate the amount of interest you'll earn on your investment
Bond       - to calculate the amount you'll have to pay on a home loan
```
